# EVMERON — Προωθητική ιστοσελίδα

Επίσημη παρουσίαση της offline εφαρμογής προσωπικών οικονομικών EVMERON για Android.

## Ιστοσελίδα
Το `index.html` είναι αυτοτελές, responsive και χωρίς εξωτερικές βιβλιοθήκες ή analytics.

## GitHub Pages
Για να ενεργοποιηθεί η δημόσια ιστοσελίδα:

1. Άνοιξε **Settings → Pages** αυτού του repository.
2. Στο **Build and deployment → Source** επίλεξε **Deploy from a branch**.
3. Επίλεξε **main** και **/(root)** και πάτησε **Save**.
4. Μετά την ολοκλήρωση του deployment, η διεύθυνση θα είναι https://schgr.github.io/Evmeron-site/

## APK
Δεν υπάρχει ακόμα δημοσιευμένο, επιβεβαιωμένο APK στο συγκεκριμένο repository. Η σελίδα παραπέμπει στο GitHub Releases και δεν περιέχει debug APK ή προσωπικά δεδομένα.

## Σημείωση
Το dashboard δείχνει **φανταστικά ποσά** για παρουσίαση. Τα στοιχεία του χρήστη δεν εμφανίζονται στην ιστοσελίδα.
